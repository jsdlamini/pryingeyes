\chapter{Configuration reference}
\label{ch:config}

All configuration comes from environment variables, normally kept in \fpath{.env}. The application validates them at start-up and refuses to run with missing or malformed values, naming the setting at fault. \fpath{.env.example} lists every setting with its development default.

\code{NODE_ENV} is managed by Next.js (\code{npm run dev} sets \code{development}, \code{npm start} sets \code{production}). It only affects build optimisation and hot reload; \code{APP_ENV} decides what's safe. If \code{APP_ENV} is unset, it follows \code{NODE_ENV}.
